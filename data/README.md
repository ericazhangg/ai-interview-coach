# Data

This folder contains the dataset and all generated evaluation outputs used by the project.

- `raw/`
  - contains the source dataset used for interview questions and reference answers
  - current file: `Software_Questions.csv`
- `evaluation/`
  - contains the fixed benchmark test cases used to compare model versions on the same inputs
  - current file: `test_cases.csv`
- `results/`
  - contains generated CSV outputs from benchmarks, prompt comparisons, baseline comparisons, and saved interview sessions
